Widget Shell
The universal container for all workspace widgets. Includes standard structural elements: a header with a label and optional top-right actions (filter, resize, pagination). The default state shows all elements, but pagination and filter are optional and users can hide them if they don't need them. Uses .workspace-widget, .workspace-widget-header, and .workspace-widget-body classes.
